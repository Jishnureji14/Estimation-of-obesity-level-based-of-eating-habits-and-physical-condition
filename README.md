Estimation of Obesity Levels Based on Eating Habits and Physical Condition


 Project Overview:

This project analyzes lifestyle and demographic factors affecting obesity levels using exploratory data analysis (EDA).


Objectives:

Analyze weight and BMI distribution

Study impact of physical activity

Examine effect of diet and screen time

Identify correlations between lifestyle habits


 Libraries Used:

pandas

numpy

matplotlib

seaborn


Key Findings:

Physical inactivity is strongly linked to obesity

High screen time shows association with higher BMI

Diet and daily habits significantly influence weight levels


 Conclusion

Obesity is influenced by multiple lifestyle factors. Healthy habits and regular physical activity play a crucial role in weight management.
